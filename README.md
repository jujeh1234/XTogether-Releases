# XTogether

Two pilots, two PCs, two X-Plane 12 installations, **one aircraft**.

XTogether synchronises an X-Plane 12 aircraft between a Captain and a First Officer: switches, knobs,
autopilot, radios, FMC keys and EFB values, with one simulator running the flight model and the other following
it. Includes an aircraft scanner, a crew check, an encrypted connection with an optional relay server, and a Solo
Test with a virtual co-pilot.

## Download

Get **`XTogether-Setup.exe`** from the [latest release](../../releases/latest). It installs the desktop
app and the X-Plane 12 plugin; no administrator rights are needed. The app updates itself from this page.

Each release also contains `SHA256SUMS.txt` with the checksums of the installer and the uninstaller.

## Requirements

- Windows 10 or 11, 64-bit
- X-Plane 12
